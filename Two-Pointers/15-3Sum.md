# LeetCode 15 - 3Sum

## 📌 Problem

Hume ek integer array `nums` diya gaya hai.

Hume array me aise **3 elements** find karne hain jinka sum:

```text
0
```

ho.

Matlab hume:

```text
nums[i] + nums[j] + nums[k] = 0
```

satisfy karne wale triplets find karne hain.

Important:

```text
Same triplet answer me duplicate nahi aana chahiye.
```

---

## 🔹 Example

```text
nums = [-1,0,1,2,-1,-4]
```

Possible triplets:

```text
[-1,-1,2]

-1 + -1 + 2 = 0
```

Aur:

```text
[-1,0,1]

-1 + 0 + 1 = 0
```

So answer:

```text
[[-1,-1,2],[-1,0,1]]
```

---

# 💡 Approach - Sorting + Two Pointers

3Sum ko directly 3 nested loops se solve kar sakte hain:

```text
for
   for
      for
```

Lekin uski Time Complexity:

```text
O(n³)
```

ho jayegi.

Better approach:

```text
1. Array sort karo
2. Ek element `i` se fix karo
3. Remaining elements par Two Pointer lagao
```

Isse problem:

```text
3Sum
```

se basically:

```text
2Sum
```

ban jaati hai.

---

# 🔹 Step 1 - Sort The Array

Original:

```text
[-1,0,1,2,-1,-4]
```

Sort karne ke baad:

```text
[-4,-1,-1,0,1,2]
```

Sorting important hai because uske baad hum decide kar sakte hain:

```text
sum chhota hai → left aage karo

sum bada hai → right peeche karo
```

---

# 🔹 Step 2 - Ek Element Fix Karo

Hum loop chalate hain:

```cpp
for(int i=0;i<n-2;i++)
```

`i` ek element ko fix karega.

Example:

```text
[-4,-1,-1,0,1,2]
 ↑
 i
```

Ab `i` fixed hai.

Remaining do elements Two Pointer se find karenge.

---

# 🔹 Step 3 - Left And Right Pointers

`i` fix karne ke baad:

```cpp
int left=i+1;
int right=n-1;
```

Example:

```text
[-4,-1,-1,0,1,2]
 ↑   ↑          ↑
 i  left       right
```

Ab hum calculate karenge:

```cpp
int sum=nums[i]+nums[left]+nums[right];
```

---

# 🔍 Three Possible Cases

Current sum ke according 3 cases honge.

---

## Case 1 - `sum == 0`

Agar:

```cpp
sum==0
```

to hume valid triplet mil gaya.

Example:

```text
-1 + -1 + 2 = 0
```

Answer me add:

```cpp
ans.push_back({nums[i],nums[left],nums[right]});
```

Then dono pointers move:

```cpp
left++;
right--;
```

---

## Case 2 - `sum > 0`

Agar:

```text
sum > 0
```

matlab current sum **bahut bada** hai.

Hume sum ko chhota karna hai.

Array sorted hai, isliye right pointer ko left side move karenge:

```cpp
right--;
```

Example:

```text
nums = [-2,0,1,5]

sum = -2 + 0 + 5
    = 3
```

`3 > 0`

Hume smaller number chahiye.

Isliye:

```text
right--
```

---

## Case 3 - `sum < 0`

Agar:

```text
sum < 0
```

matlab current sum **bahut chhota** hai.

Hume sum bada karna hai.

Sorted array me left pointer ko right side move karne se bigger value milegi.

So:

```cpp
left++;
```

---

# 🧠 Pointer Movement Yaad Rakho

```text
sum < 0
   ↓
sum chhota hai
   ↓
bada number chahiye
   ↓
left++
```

```text
sum > 0
   ↓
sum bada hai
   ↓
chhota number chahiye
   ↓
right--
```

```text
sum == 0
   ↓
answer mila
   ↓
store triplet
   ↓
left++
right--
```

# 🚫 Duplicate Triplets Problem

3Sum me same triplet multiple times nahi aana chahiye.

Example sorted array:

```text
[-4,-1,-1,0,1,2]
     ↑  ↑
```

Yahan `-1` multiple times hai.

Agar hum dono `-1` ko separately `i` bana kar process kare, duplicate triplets aa sakte hain.

Isliye duplicate `i` ko skip karte hain.

---

# 🔥 Duplicate `i` Ko Skip Karna

Code:

```cpp
if(i>0 && nums[i]==nums[i-1]){
    continue;
}
```

Iska matlab:

```text
Agar current nums[i]
previous nums[i-1] ke same hai

→ ye number already process ho chuka hai

→ skip karo
```

Example:

```text
[-4,-1,-1,0,1,2]
     ↑  ↑
    old new
```

Pehla `-1` process ho chuka hai.

Jab second `-1` `i` banega:

```text
nums[i] == nums[i-1]
```

true hoga.

So:

```cpp
continue;
```

---

# ❓ `i > 0` Kyu?

Because hum:

```cpp
nums[i-1]
```

access kar rahe hain.

Agar:

```text
i = 0
```

to:

```text
i-1 = -1
```

ho jayega.

```cpp
nums[-1]
```

invalid hai.

Isliye pehle check:

```cpp
i>0
```

---

# ❓ `nums[i] == nums[i-1]` Kyu?

Hum current element ko **previous element** se compare karte hain:

```cpp
nums[i]==nums[i-1]
```

because hume check karna hai:

```text
Kya ye value pehle already process ho chuki hai?
```

Agar previous same hai, matlab answer us value ke liye already search kar chuke hain.

---

# ❌ `nums[i] == nums[i+1]` Kyu Nahi?

Agar hum likhen:

```cpp
nums[i]==nums[i+1]
```

to hum **first occurrence ko hi skip** kar sakte hain.

Example:

```text
[-4,-1,-1,0,1,2]
     ↑  ↑
     i
```

Current `i` pe first `-1` hai.

Next bhi `-1` hai.

Condition:

```text
nums[i] == nums[i+1]
```

true ho jayegi.

Aur hum first `-1` ko hi skip kar denge.

Lekin isi first `-1` se valid answers milne the:

```text
[-1,-1,2]

[-1,0,1]
```

Isliye first occurrence ko process karna hai.

**Baad wale duplicate occurrences ko skip karna hai.**

Correct:

```cpp
if(i>0 && nums[i]==nums[i-1])
```

---

# 🔥 Left Pointer Ke Duplicates

Valid answer milne ke baad:

```cpp
left++;
right--;
```

karte hain.

Lekin `left` par duplicate values ho sakti hain.

Isliye:

```cpp
while(left<right && nums[left]==nums[left-1]){
    left++;
}
```

Matlab:

```text
Agar new left ki value
previously used left value ke same hai

→ skip karo
```

---

# 🔥 Right Pointer Ke Duplicates

Same way:

```cpp
while(left<right && nums[right]==nums[right+1]){
    right--;
}
```

`right--` already kar chuke hain.

Isliye previous used right element ab:

```text
right + 1
```

position par hai.

Agar:

```text
nums[right] == nums[right+1]
```

to duplicate hai.

So:

```cpp
right--;
```

# 💻 C++ Code

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> ans;
        int n=nums.size();

        sort(nums.begin(),nums.end());

        for(int i=0;i<n-2;i++){

            if(i>0 && nums[i]==nums[i-1]){
                continue;
            }

            int left=i+1;
            int right=n-1;

            while(left<right){

                int sum=nums[i]+nums[left]+nums[right];

                if(sum==0){

                    ans.push_back({nums[i],nums[left],nums[right]});

                    left++;
                    right--;

                    while(left<right && nums[left]==nums[left-1]){
                        left++;
                    }

                    while(left<right && nums[right]==nums[right+1]){
                        right--;
                    }
                }

                else if(sum>0){
                    right--;
                }

                else{
                    left++;
                }
            }
        }

        return ans;
    }
};
```

# 🧠 Code Explanation

## 1. Answer Vector

```cpp
vector<vector<int>> ans;
```

Har answer ek triplet hoga:

```text
[a,b,c]
```

Aur multiple triplets store karne hain.

Isliye:

```cpp
vector<vector<int>>
```

use kiya.

---

## 2. Sort

```cpp
sort(nums.begin(),nums.end());
```

Sorting Two Pointer movement possible banati hai.

---

## 3. `i` Ko Fix Karna

```cpp
for(int i=0;i<n-2;i++)
```

Har iteration me ek number fix karte hain.

`n-2` tak hi jaate hain because triplet banane ke liye `i` ke baad minimum 2 elements chahiye.

---

## 4. Duplicate `i`

```cpp
if(i>0 && nums[i]==nums[i-1]){
    continue;
}
```

Same fixed element ko dobara process nahi karna.

---

## 5. Two Pointers

```cpp
int left=i+1;
int right=n-1;
```

`left`:

```text
i ke just next element
```

`right`:

```text
array ka last element
```

---

## 6. Sum

```cpp
int sum=nums[i]+nums[left]+nums[right];
```

Current 3 elements ka sum calculate karte hain.

---

## 7. Valid Triplet

```cpp
if(sum==0)
```

Answer mila:

```cpp
ans.push_back({nums[i],nums[left],nums[right]});
```

Then:

```cpp
left++;
right--;
```

Aur duplicates skip karte hain.

---

## 8. Sum Bada Hai

```cpp
else if(sum>0){
    right--;
}
```

Sorted array me `right--` karne se smaller number milega.

---

## 9. Sum Chhota Hai

```cpp
else{
    left++;
}
```

Sorted array me `left++` karne se bigger number milega.

# ⏱️ Time Complexity

Sorting:

```text
O(n log n)
```

Outer loop:

```text
O(n)
```

Har `i` ke liye Two Pointer:

```text
O(n)
```

Overall dominant complexity:

```text
O(n²)
```

---

# 💾 Space Complexity

Answer ko ignore karke Two Pointer approach extra major data structure use nahi karta.

```text
O(1)
```

Sorting implementation internally kuch extra space use kar sakti hai, but Two Pointer logic constant extra space use karta hai.

# 🧩 Pattern To Remember

```text
3Sum = Sorting + Fix One Element + Two Pointers
```

Ek element fix karne ke baad problem basically ban jaati hai:

```text
Find two remaining numbers
```

Aur sorted array hone ki wajah se un dono numbers ko Two Pointer se efficiently find kar sakte hain.
